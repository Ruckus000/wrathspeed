# Bundled content licenses

Wrathspeed v1 does not ship third-party exercise videos.

- Exercise stills use Apple SF Symbols.
- Movement names and cues in `WrathspeedCore/Sources/WrathspeedCore/Resources/strength_catalog.json` are original text for this app.
- Training paces use the published Jack Daniels VDOT formulas and the Riegel race-time formula.

If short CC-licensed clips are added later, list each file, source URL, and license here.
